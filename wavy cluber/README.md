# Wavy cubes

Run `npm.cmd start`, then open http://localhost:5173.
No installation or build step is required.

This is a local adaptation of https://projects.arkon.digital/threejs/wavy-cubes/
by Franky / Arkon Digital. It retains the reference's compiled Three.js and
GSAP animation, styling, portfolio copy, and outgoing links. Assets are served
locally; the Inter font is requested from Google Fonts with a sans-serif fallback.

Edit `index.html` to personalize the name, biography, location, and links.
Edit `reference.css` for layout and typography. The original animation bundle
is in `reference.js`. Move your pointer over the grid to create ripples;
idle ripples start automatically. Append `#debug` to access the original
animation controls.
